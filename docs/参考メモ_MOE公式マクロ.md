## 公式マクロの しくみ（要点）
- **1つのマクロは 6行。** 1行に コマンドを1つ書く（Command1〜Command6）。
- **ボタン1つに マクロ1つ。** ショートカット（またはメニューバー）のボタンを 右クリック → MacroEditor で書く。押すと 上から順に動く。
- 装備やアイテムを ショートカットへ ドラッグすると、自動でマクロになる（装備は `/equipitem [名前] tgl`）。
- 先頭は半角の `/`。スペースも半角だけ。

## おもなコマンド
| コマンド | すること | 例 |
|---|---|---|
| `/cmd [技名]` | 技・魔法を使う | `/cmd [ヒーリング オール]` |
| `/pause 数` | 待つ | `/pause 13` |
| `/useitem [名前]<対象>` | アイテムを使う。`<1>`=自分、`<2>`〜`<5>`=PTメンバー、`<t>`=ターゲット | `/useitem [*バンデージ*]<1>` |
| `/equipitem [名前]` | 装備する。末尾 `left`=左手、`tgl`=つける/はずす | `/equipitem [*ソード*]` |
| `/target 名前` | ターゲットする | |
| `/ass [名前]` | 仲間と同じ相手をターゲット | |
| `/say` `/party` | 発言・PTチャット。`%mpp`（MP%）などが使える | `/party 残りＭＰは%mpp%` |
| `/emote` `/dice` など | そのほか | |

`[*ソード*]` のように `*` を使うと、名前の一部でえらべる。

## 待ち（/pause）
- **`/pause 1` ≒ 0.1秒（正確には 0.096秒 ＝ ディレイ6）。**
  - 0.2秒 ≒ `/pause 2`、1秒 ≒ `/pause 10`、8秒 ≒ `/pause 80`。
- いちばん小さい・大きい数は、どのページにも書いていなかった。例では 1〜80 が使われていた。
- 待っている間は、ほかのマクロ（技・魔法・アイテム）は使えない。歩く・走るは できる。
- スタミナの残りで ディレイが変わるので、数は自分で合わせる。

## 知っておくこと
- **押すたびに次の技:** `/cmd` を ならべると、1回目は1行目の技、ディレイ中に もう1回押すと2行目の技…と出る（技をまとめる使いかた）。
- **先行入力:** 最後に入れた技は、ディレイが たまると 自動で出てしまう。ふせぐため、最後の行に「使えない技」を入れる（`/cmd [美容]` `/cmd [採掘]` など）。
- **多段技**（バルクショットなど）には、途中に `/pause` や 持ちかえを入れないほうがよい（とちゅうで止まる）。
- **アンチマクロ:** 公式 FAQ では、同じ行動を くりかえすと スキルの上がりが にぶることがある、とある。

## 例（公式のやりかた）
- 3回つづけて収穫:
  `/cmd [収穫(刈る)]` → `/pause 40` → `/cmd [収穫(刈る)]` → `/pause 40` → `/cmd [収穫(刈る)]` → `/cmd [美容]`
- 盾技を出して 両手武器に もどす:
  `/equipitem [*カイト シールド*]` → `/cmd [シールド ガード]` → `/pause 13` → `/equipitem [*グレート ソード*]`
- 魔法の詠唱（1回目で詠唱、2回目で発動）:
  `/equipitem [*ブック*]` → `/cmd [ヒーリング オール]` → `/pause 1` → `/equipitem [*ソード*]`
- MP回復を仲間に知らせる:
  `/cmd［メディテーション］` → `/party ＭＰ回復中です。残りＭＰは%mpp%`

## このゲーム（life-rpg）の いまの形と ちがい
| | 公式 MOE | いまの life-rpg |
|---|---|---|
| 1マクロの長さ | 6行 | 3枠（技A → 待ち → 技B） |
| 待ちの細かさ | 約0.1秒きざみ（`/pause 1`） | 1秒きざみ（1〜60秒） |
| 中に入れられるもの | 技・待ち・アイテム・装備・ターゲット・発言 | 技（プレイヤー①・ペット・鳳凰・龍神）と待ち |
| 書きかた | 文字で書く | 枠へ ドラッグ・待ちは リストから |
| マクロの数 | ボタンの数だけ | 1〜10 |

### 公式によせる案（まだ作っていない）
1. 枠を **6行** にする。1行ずつ「技」か「待ち」をえらぶ（いまのドラッグのまま）。
2. 待ちを **0.1秒きざみ**（`/pause` と同じ）にする。リストは 0.1〜8.0秒くらい。
3. 「押すたびに次の技」と「最後に先行入力止め」は、あとで考える。
4. 前のマクロ（技A・待ち・技B）は、新しい6行の 1〜3行目に そのまま うつす。
