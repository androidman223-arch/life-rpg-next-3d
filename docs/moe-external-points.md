# 外部ポイント（2026-10-20）

ホームの鳳凰・龍神と、フィールドのペット経験値は、別の保存です。ここは今日入れた仕組みの説明です。

## 画面で見えているもの

ホームのレベル・ジョブの下に、鳳凰と龍神が1枚ずつあります。それぞれ1行です。

- **P** … このゲームの中で稼いだ分
- **外部P** … 休憩ポップアップ（クラウドのメモ整理・チャット相談）から来た合計
- **合計** … P と外部P を足した数

外部Pは、取りこみボタンを押すまで 0 のままです。

## 休憩ポップアップのファイル

読むだけです。ゲーム側から書きかえません。

`C:\Users\Owner\Desktop\kyukei_popup\points_kei.json`

中身の例:

```json
{"phoenix":335.5,"phoenixMemo":205.5,"phoenixChat":130.0,"dragon":0.3,"updated":"2026-10-20T22:42:42"}
```

- `phoenix` は鳳凰Pの合計です。メモ分とチャット分は、すでにこの数字に入っています。
- `phoenixMemo` と `phoenixChat` は内訳です。`phoenix` に足しません。
- `dragon` は龍神Pの合計です。

読み口は `GET /api/phoenix-points`（`src/app/api/phoenix-points/route.js`）。ファイルが無いときは取りこめず、保存は変えません。

## 入れかえ（足さない）

ボタンはホームのカードの下、「フェニックスP外部取りこみ」です。

押すと、ゲームの中の「休憩ポップアップから来た分」だけを、ファイルの合計で入れかえます。ゲーム内の P には足しません。

同じファイルを何回読んでも、外部Pは同じ数字です。増えていきません。ファイルの合計が 338.7 なら、外部鳳凰Pはいつも 338.7 です。前回の外部Pが 100 でも 300 でも、読み直したあとは 338.7 です。

結果の文章は「入れかえました。外部鳳凰P … ／ 外部龍神P …」だけです。10秒で消えます。もう一度押すと、その時点からまた 10 秒です。

別枠の保存キーは `life-rpg-moe-break-popup-points-v1` です。処理は `src/lib/moePhoenixPointsImport.js`。

## ゲーム内の P

鳳凰の知恵EXPと龍神の実践EXPは、localStorage の `life-rpg-moe-player-experience` です。

- 知恵EXPは `phoenixWisdomExp`
- 龍神の実践は `dragon`（level と、次の 0.1 までの exp）
- 同じファイルに、スキル熟練度（phoenix / heal / stealth / preSkills）も入っています

これは修行タイマーや武練が書く分です。外部Pとは別です。表示の合計だけ、その場で足しています。

## ペット経験値の外部保存（別の機能）

3Dフィールドの **設定** → **ペットEXPを保存** です。

`moe-save-*.json` を新しく追加保存します。前のファイルは上書きしません。戻すときは、その JSON を1つ選びます。

ペットの累計は `life-rpg-moe-pet-progress` の `byId[ペットID].totalExp` です。書き込みは `src/lib/moePetSave.js` の `persistCurrentMoePet`。戦闘やアイテムで増えるたびにすぐ保存されます。ホームの鳳凰・龍神には入りません。

## 混ぜないこと

休憩ポップアップのボタンは、ゲーム内EXPへ足す道ではありません。

`trainingExpAdd` という別口だけ、JSON を読んだときにゲーム内の知恵・実践へ足します。通常のペット用セーブに入っている `trainingExp` の控えは、読み込んでも足しません。同じ加算ファイルを二度読むと、その分がもう一度足されます。
