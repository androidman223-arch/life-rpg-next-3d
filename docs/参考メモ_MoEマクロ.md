## 公式のマクロの形
- メニューの スロット（わく）を 右クリック → 「マクロ登録」画面。
- 1つのマクロ:
  1. **タイトル**（スロットに出る名前。色もかえられる）
  2. **アイコン**（アイコン選択画面から えらぶ）
  3. **コマンド 1〜6**（**6行まで**。上から順に 実行）
- CLEAR → OK で けす。ドラッグで コピーできる。
- メニューの 1〜4ページは 決まった機能、5ページめから 自由に置ける。

## 待ち（/pause）
- `/pause 数字` … つぎの行まで 待つ。
- 単位: **/pause 1 ≒ 0.1秒**（正確には 0.096秒。ファンページ2つ）。公式には 単位は書いていない。
  - 公式: 技や魔法の アイコンに出る「DELAY」の数を そのまま /pause に書く（例 `/pause 20`）。
- よく使う数: 1・10・13・18・20・30・40・80。
- /pause の あいだは、ほかのマクロ（技・魔法・アイテム）は うけつけない。歩くのは できる。

## よく使うコマンド
- 技・魔法: `/cmd [ヒーリング]`（魔法は 先に本を持つ `/equipitem [*ブック*]`）
- アイテム: `/useitem [*バンデージ*] <1>`（<1>=自分、<2>〜<5>=パーティ、<t>=ターゲット）
- 装備: `/equipitem [*ソード*]`・`left`（左手）・`tgl`（つけはずし）
- ターゲット: `/target <pet>`・`/assist`・`/locktarget on`
- `*` は なんでも合う文字（ワイルドカード）。
- さいごに 覚えていない技（`/cmd [美容]` など）を 入れて、よけいな 予約を けす 小わざ。

## 例
- 盾にもちかえて ガード → もどす:
  `/equipitem [*カイト シールド*]` / `/cmd [シールド ガード]` / `/pause 13` / `/equipitem [*グレート ソード*]`
- 本を持って 全体回復 → もどす:
  `/equipitem [*ブック*]` / `/cmd [ヒーリング オール]` / `/pause 1` / `/equipitem [*ソード*]`
- 3回 くりかえし: `/cmd [採掘]` / `/pause 30` / `/cmd [採掘]` / `/pause 30` / `/cmd [採掘]`

## 置きかえ文字（チャット・マクロで使える）
- `%hp` `%hpp`（HP・HP%）、`%mp` `%mpp`（MP・MP%）、`%st` `%stp`（スタミナ）
- `%t`（ターゲットの名前）、`%l`（いまの場所）、`%p`（座標）、`%dir`（向き）、`%1`〜`%5`（パーティの名前）

## このゲームでの まね（2026-11-10）
- 1つのマクロ = **タイトル ＋ 6行**。1行は「技」か「待ち（/pause）」。
- 待ちは /pause と同じ 0.1秒きざみ（1 = 0.1秒）。えらべるのは 0.1秒〜6秒。
- アイコンは、いちばん上の技の アイコンを そのまま使う（えらぶ画面は まだ）。
- 前の「技A → 待ち → 技B」の マクロは、そのまま 6行の形に うつす。
- 装備・アイテム・置きかえ文字は まだ（このゲームに そのしくみが ないため）。
