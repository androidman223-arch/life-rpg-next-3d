# マクロ４ — タイマー付き（分数おまかせ）

**マクロ０〜３** = 作業の種類 · **マクロ４** = **時間箱**（画面上タイマー＋分数で厚さを決める席外し）

## 呼び方（追加質問しない）

| 言い方例 | 解釈 |
|----------|------|
| **マクロ４ おまかせ** | デフォルト **30分** 箱 |
| **10分マクロ４ おまかせ** | 10分箱 |
| **60分マクロ４ ゆったり** | 60分箱 · L1〜L5 1周目標 |
| **マクロ４ タイマー終了まで** | ユーザーが画面タイマーを回している前提で、0:00 手前まで作業 |

旧呼び方 **休マクロ（30）** / **寝マクロ（60）** も有効（中身は本スキルの分数表）。

---

## 画面上のタイマー（必ず案内）

ホーム or MOEフィールド上部 **「⏱ マクロ４」** → **10 / 20 / 30 / 45 / 60分** → **1秒ごと MM:SS カウントダウン**（0:00 で終了）。

- コード: `src/lib/moeMacroSessionTimer.js` · `MoeMacroSessionTimer.jsx`
- `sessionStorage` でタブ内復元
- チャット開始時: 「画面で ○分タイマーを回してね」と一言してもよい（ユーザーが既に回していれば省略）

---

## 時間 → 作業量

| 指定 | 打切り上限 | 成果の目安 | 手動確認 |
|------|-----------|-----------|----------|
| **〜10分** | 15分 | L1 or L2 を **1面厚く** | 1 |
| **〜20分** | 25分 | 1面 L2+L3 | 1〜2 |
| **〜30分** | 40分 | [macro-30/QUEUE.md](../macro-30/QUEUE.md) 先頭1件完遂 | 1 |
| **〜45分** | 55分 | 1面 L1〜L4 | 3 |
| **〜60分** | 75分 | 1面 **L1〜L5 1周** or AGE 2面 L2+L3 | 5 |
| **90分+** | — | 分割提案（60+30） | — |

### L厚さチェック（骨組みだけで終わらない）

- **L1** 地形・看板・リム
- **L2** プロップ **3点+**
- **L3** 湧き pad / 座標
- **L4** 動く演出 **1つ+**
- **L5** Wiki メモ **1行**

## サイクル

1. 分数を決める（未指定なら **30分**）
2. QUEUE 先頭 or ユーザー指定
3. 設計3行（mapSlotId · ファイル · L層）
4. 実装（厚さチェック）
5. `npm run smoke`
6. 終了報告（**マクロ４ · ○分 · 完了L層 · タイマー連動したか**）
7. QUEUE に `✅ 日付`
8. **サークル間クールダウン約20秒**（次のサイクルへ進む前 · 下記）

### サークル間クールダウン（必須 · 約20秒）

**1サークル** = QUEUE 1件の完遂 + smoke + 終了報告。

完了直後に **約20秒、何もしない待機**（ファイル編集・コマンド・次キュー着手なし）。

- ユーザー向け: 「長い作業のため、20秒ほど機械を休ませます」
- 連続で複数サークルを回さない（1タイマー枠 = 基本 **1サークルまで**）
- 60分枠でも **2サークル目に入る前** に必ず同じクールダウン

### 終了報告テンプレ

```
【マクロ４ · ○分】完了（打切り上限 ○分）
・面: mapSlotId
・L: L1✓ L2✓ …
・タイマー: 画面○分 / チャットのみ
・smoke: pass
・手動: ①…
```

---

## やらないこと

- 分数に対して薄い骨組みだけで終了
- 90分を1セッションで抱えない
- 分数・マクロ４指定があるのに聞き返す
- サークル完了後、20秒クールダウンを飛ばして次のサイクルへ突入
