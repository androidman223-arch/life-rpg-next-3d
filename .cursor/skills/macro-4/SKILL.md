# マクロ４ — サークル制（Cursor で回数カウント · 指定回数いっぱい回す）

**マクロ０〜３** = 作業の種類 · **マクロ４** = **回数箱**（**指定サークル数まで** QUEUE を回す席外し）

> **マクロ４ 3サークル おまかせ** = 「3件完遂するまで止めない」こと。1件で終わらせない。

**時間制は使わない。** 分数・タイマー・tick ループは指定しない（ゲーム内 ⏱ はユーザー任意のおまけのみ）。

---

## 呼び方（追加質問しない）

| 言い方例 | 解釈 |
|----------|------|
| **マクロ４ おまかせ** | デフォルト **3サークル** |
| **マクロ４ 3サークル おまかせ** | **3サークル** 完遂まで |
| **マクロ４ 5回** / **5サークル** | **5サークル** 完遂まで |
| **マクロ４ 続き** | 前回の箱が切れた再開（残りサークルがあれば継続） |

### 旧呼び方 → サークル数への換算（参考のみ · ユーザーが分数を言ったらこれに寄せる）

| 旧 | サークル数 |
|----|-----------|
| 休マクロ（30） / 10分 | **2〜3サークル** |
| 30分マクロ４ | **3〜4サークル** |
| 寝マクロ（60） / 50分 | **5〜8サークル** |

## サークルカウンター（本筋 · 作業の前に必ず表示）

ゲーム内 **⏱ マクロ４** はおまけ（別タブ用 · Cursor とは非連動）。**エージェントはチャットでサークル残数を主役にする。**

### 0. 作業着手前（必須 · 最初の返答）

**いかなる編集・コマンドの前に**、次を1ブロックで出す：

```
🔄 マクロ４ · Nサークル 開始
・残り: N サークル（完了 0 / 指定 N）
・QUEUE: macro-30 / macro-60 など
・方針: 残り 0 になるまで回す（1件で止めない）
```

### 1. サークル完了時（必須）

各サークル後に **残りサークル数** を必ず添える：

```
🔄 残り 2 サークル · サークル 1 完了（1/N）
・面: mapSlotId · L層
・smoke: pass / fail
```

### 2. 途中進捗（5サークル以上の箱）

| 指定サークル | 進捗報告 |
|-------------|----------|
| 1〜3 | 各サークル終了時のみ |
| 4〜6 | 各サークル ＋ 完了面リスト |
| 7+ | 各サークル ＋ 完了面リスト |

### 3. 終了時（残り 0 · または延長完遂後）

```
【マクロ４終了】指定 Nサークル · 実働 Nサークル（延長 ○サークル含む）
・残り: 0 サークル
・完了一覧: …
・smoke: 最終 pass
・手動確認: ①…
```

### 3b. 最終サークルで実装が未完了 → **延長（必須）**

**残り 0 になっても、着手済みサークルの実装が終わっていなければ止めない。**

| 状態 | 動き |
|------|------|
| smoke **未**pass · ファイル半端 · L層の途中 | **延長** → smoke pass ＋ サークル報告まで完遂 |
| 残り 0 で **次の新サークル** に入ろうとしている | **開始しない**（延長は現サークル完遂のみ） |
| 現サークル完遂済み · 残り 0 | 終了報告して止める |

延長中のチャット：

```
🔄 残り 0 だが実装完遂まで延長中
・残り作業: smoke 修正 / L3 pad 仕上げ など
・延長目安: 完遂まで（新サークルは開始しない）
```

### 4. サークル間クールダウン（約20秒 · ループは続ける）

**1サークル** = QUEUE 1件の完遂 + smoke + 上記の残りサークル付き報告。

完了直後 **約20秒、何もしない**（編集・コマンド・次キュー着手なし）。

- チャットに: `🔄 残り N サークル · 20秒ほど機械を休ませます`
- **クールダウン後、残りサークル ≥ 1 なら次サークルへ**
- 残り 0 かつ現サークル完遂済み → 終了報告（**実装途中なら §3b 延長**）

| サークル数 | だいたいの所要 | 1サークルの目安 | キュー |

## サイクル（1サークル）

1. **残りサークル数を確認**（0 かつ実装未完了なら §3b 延長 · 完遂済みなら終了報告のみ）
2. QUEUE 先頭 or 続きの面
3. 設計3行（mapSlotId · ファイル · L層）
4. 実装（厚さチェック）
5. `npm run smoke`
6. サークル報告（**残り N サークル 必須**）
7. QUEUE に `✅ 日付`
8. **約20秒クールダウン** → 残り ≥ 1 なら **1に戻る**

---

## 中断・再開

- チャット切断・ユーザー停止 → 次回 **「マクロ４ 続き」** で残りサークルを再開
- 再開時も **作業前に** `🔄 残り N サークル · 再開` を表示

---

## やらないこと

- 指定サークル数の **途中で1サークルだけ** やって終わる
- 薄い骨組みだけでサークル完了扱い
- 9サークル超を1セッションで抱えない（分割提案）
- サークル数・マクロ４指定があるのに聞き返す
- **サークル開始表示なし** でいきなり編集する
- サークル完了後、20秒クールダウンを飛ばして次へ突入
- **残り 0 を理由に実装途中で打ち切る**
- **時間制・分数・tick ループで進行管理する**（ユーザーが明示した場合のみ分数→上表でサークル数に換算）
