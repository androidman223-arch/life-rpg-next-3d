# マクロ30 — 休マクロ（〜30分 · 1サイクル）

## おまかせ実行

ユーザーが **「休マクロ」**（または 30分マクロ / 休憩マクロ）だけ言ったら **追加質問しない**。

1. 本スキルを読む
2. [QUEUE.md](QUEUE.md) の **先頭の未着手** を1件選ぶ
3. サイクル（選ぶ→やる→smoke→終了報告）まで **最後まで** 実行
4. QUEUE に `✅ 日付` を付ける

ユーザーが別タスクを指定したときだけ、その指定を優先する。

## 指令

**席を外しても無駄にならない、小さく確実な1成果。**

| 項目 | ルール |
|------|--------|
| **時間** | 目安 **25〜35分** · **40分超えたら打ち切り**して終了報告 |
| **成果** | **1テーマだけ**（下のキューから1件） |
| **禁止** | 2面以上のマクロ１敵 · MoeFieldMap 大分割 · 60分マクロの仕事を半分やる |
| **必須** | 終わりに `npm run smoke` · 変更ファイル一覧 · 手動確認1行 |

## 呼び方

- **推奨:** **休マクロ**（おまかせ可）
- **OK:** 30分マクロ / 休憩マクロ / マクロ30 / コーヒーブレイク

## サイクル（固定 · 4ステップ）

### 1. 選ぶ（2分）

[QUEUE.md](QUEUE.md) から **先頭の未着手** を1件。ユーザー指定があればそれを優先。

### 2. やる（20〜25分）

- 純粋ロジックは `src/lib/` に切る（AGENTS.md）
- 永続化キーは `moeStorageRegistry.js` に登録
- `MoeFieldMap.jsx` に直書きロジックを増やさない（既存配線のみ）

### 3. 検証（5分）

```bash
npm run smoke
```

### 4. 終了報告（4行テンプレ）

```
【休憩マクロ30】完了
・やったこと: （1行）
・触ったファイル: （最大5件）
・smoke: pass / fail
・手動: （例: ユグ海岸アルター転送で確認）
```

QUEUE の該当行を `✅` に更新。

## 中断・再開

- **いつでも中断OK** — 終了報告に `中断: 次は QUEUE #n から` と書く
- 次セッションは同じ QUEUE 行を再開（コミットはユーザー依頼時のみ）

## やらないこと

- 60分マクロの仕事（マクロ１敵完走 · AGE 1面 L1〜L4 など）
- git commit / push（ユーザーが言ったときだけ）
- 20機能マクロの複数件を1回で消化
